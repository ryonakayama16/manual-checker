# 業務マニュアル品質診断ツール

株式会社2.1 中山亮 著書「図解いちばんやさしく丁寧に書いた 業務マニュアルの作成」の基準に基づくAI診断WEBサービス。

## 機能
- PDFアップロードによるマニュアル診断
- 視認性・可読性・判読性・構成・フォーマット・検索性の6カテゴリ評価
- S〜Dのランク評価
- 強み・改善ポイントのフィードバック

## セットアップ

```bash
npm install
```

## 環境変数

`.env.local` を作成し以下を設定：

```
ANTHROPIC_API_KEY=your_api_key_here
```

## 開発サーバー起動

```bash
npm run dev
```

## デプロイ（Vercel）

Vercelの環境変数に `ANTHROPIC_API_KEY` を設定してデプロイ。
